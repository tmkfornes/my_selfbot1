# SelfBot (نسخه دیباگ‌شده)

## ساختار پروژه (لایه‌ای)

هیچ فیچری عوض نشده — فقط `main.py` (که ۱۰۰۰+ خط بود) به لایه‌های مجزا تقسیم شد:

| فایل | لایه | مسئولیت |
|---|---|---|
| `telegram_layer.py` | Telegram | ساخت `TelegramClient` — تنها جایی که کلاینت ساخته می‌شه |
| `event_layer.py` | Event | ثبت شنونده‌های Telethon (پیام خروجی + شنونده‌های خود Meowie) |
| `message_parser.py` | Message Parser | تبدیل متن خام به `ParsedCommand` (cmd/arg/body) |
| `command_router.py` | Command Router | جدول تطبیق دقیق نام دستور روی پلاگین |
| `agent_router.py` | Agent Router | وقتی دستور شناخته نشد، می‌ره سمت هوش مصنوعی |
| `ai_agent.py` | AI Layer | اتصال به OpenRouter (بدون تغییر) |
| `dispatcher.py` | Dispatcher | اعتبارسنجی JSON مدل + صدا زدن پلاگین درست (بدون تغییر) |
| `target_resolver.py` | Target Resolver | پیدا کردن طرف با ریپلای/آیدی/یوزرنیم/اسم (بدون تغییر) |
| `plugins/*.py` | Plugin Executor | خودِ دستورها — هر گروه تو فایل خودش (`core`, `media`, `moderation`, `social`, `panel`, `ai_chat`, `meowie`) |
| `command_loop.py` | — | پولینگ فایل کنترل (از `control_bot.py`) — کانال جدا از تلگرام |
| `main.py` | — | فقط لایه‌ها رو به هم وصل می‌کنه و کلاینت رو اجرا می‌کنه |

اضافه کردن پلاگین جدید: یه فایل تو `plugins/` بساز، توش `register(...)` رو صدا بزن، و یه خط `from plugins import <ماژول>` به `plugins/__init__.py` اضافه کن — نه `dispatcher`، نه `ai_agent`، نه `command_router` نیازی به تغییر ندارن (مگر اینکه بخوای با نام دقیق هم قابل صدا زدن باشه، که اون‌وقت یه `elif` تو `command_router.py` اضافه می‌کنی).


## راه‌اندازی

1. نصب پکیج‌ها:
   ```
   pip install -r requirements.txt
   ```
2. فایل `.env.example` را کپی کن و اسمش رو بذار `.env`، بعد مقادیر رو پر کن:
   - `API_ID` و `API_HASH` از https://my.telegram.org
   - `BOT_TOKEN` از @BotFather (توکن بات کنترل)
   - در صورت استفاده از پروکسی محلی (مثل V2RayN)، `PROXY_HOST`/`PROXY_PORT` رو پر کن، وگرنه خالی بذار.
3. اجرا:
   ```
   python start.py
   ```
   بار اول ازت شماره تلفن و کد تایید تلگرام رو می‌پرسه (برای ساخت session).

## دستورات

داخل چت خودت (پیام صادر شده با prefix `.`):
- `.clock on` / `.clock off`
- `.ping`
- `.status`

از طریق بات کنترل در تلگرام:
- `/clock_on` `/clock_off` `/ping` `/status`

## چه چیزهایی درست/بهتر شد

- **باگ امنیتی جدی**: توکن بات و API_HASH داخل کد هاردکد شده بودند؛ حالا از فایل `.env` خونده می‌شن و در ریپو/زیپ قرار نمی‌گیرند.
- **وابستگی گم‌شده**: `control_bot.py` از پکیج `python-telegram-bot` استفاده می‌کرد ولی داخل `requirements.txt` نبود.
- **کد تکراری**: منطق ساعت هم داخل `main.py` هم داخل `clock.py` (بدون استفاده) نوشته شده بود؛ الان فقط یک نسخه داخل `clock.py` هست و `main.py` از همون استفاده می‌کنه.
- **مدیریت Rate Limit**: تلگرام تغییر مکرر نام پروفایل رو محدود می‌کنه (FloodWaitError)؛ قبلاً این خطا کرش می‌کرد یا نادیده گرفته می‌شد، الان به‌درستی صبر می‌کنه و دوباره تلاش می‌کنه.
- **پروکسی اجباری**: قبلاً پروکسی V2Ray همیشه فعال بود، حتی اگه سرویس روی سیستم بالا نبود (باعث می‌شد اتصال اصلاً برقرار نشه). الان اختیاریه.
- **پایداری**: `start.py` حالا اگه یکی از دو پروسه کرش کنه، به‌جای سکوت، دوباره راه‌اندازیش می‌کنه.
- **رنگ و لاگ بهتر**: خروجی ترمینال حالا با رنگ و آیکون مشخص می‌شه (اطلاعات/موفقیت/هشدار/خطا).
- **دستور status اضافه شد** هم در چت هم در بات کنترل.
